Workspace quotas

Every site counts toward these limits. Storage includes every saved revision: a file kept in two revisions counts twice. Publishing an existing revision uses no extra storage.

{{template "quota-budget" .Quota.Workspace}}

The service allows up to {{maxQuotaSites}} sites and {{maxQuotaStorage}} per workspace. Lowering a limit keeps existing sites and revisions. It blocks further growth for that resource until there is room.

Group quotas

Use a group to budget for a project. Each site can count toward one group. All groups share the available workspace capacity.

Assign existing sites before setting the first group limit. Once a group has an explicit limit, only admins can add storage to unassigned sites.
